# 关于站长

> 桃花岛是一份属于 **JIAFLY** 的技术笔记。这里既是面试时随时能翻的"八股仓库"，也是工程上线前回头看的"配方手册"。

---

## 这个站点是怎么来的？

- 站长是一名 Java 后端工程师，长期在一线写代码、上线、救火；
- 内容来源：日常踩坑总结 + 阅读笔记 + 面试整理 + AI 工程实战；
- 目标：**写自己读得懂、未来还会回来翻的东西**，而不是搬运 + 凑字数。

---

## 内容定位

- **混合风格**：八股 + 系统讲解。考点要背得快，原理要看得深；
- **拒绝灌水**：每篇都是可独立吃透的最小知识单元；
- **持续打磨**：上线 ≠ 完成，每隔一段时间会回头修订。
